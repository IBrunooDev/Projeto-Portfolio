## Sobre o projeto

O portfólio foi criado para apresentar minha evolução na tecnologia e demonstrar, por meio de projetos independentes, meus conhecimentos em desenvolvimento web, interfaces responsivas e automações.

- **Foco profissional:** Desenvolvimento Front-End.
- **Localização apresentada no site:** Osasco, São Paulo, Brasil.
- **Tecnologias principais:** HTML5, CSS3 e JavaScript.
- **Formato:** site estático com várias páginas; não utiliza framework ou etapa de build para ser executado.
- **Objetivo:** apresentar projetos, formação, habilidades e facilitar o contato para oportunidades profissionais, freelances e colaborações.

## Funcionalidades

- **Layout responsivo:** estilos adaptados para diferentes larguras de tela.
- **Navegação compartilhada:** menu presente nas páginas e indicação da página atual.
- **Menu mobile:** menu expansível com botão, fechamento ao navegar e suporte à tecla `Escape`.
- **Identidade visual consistente:** fundo navy, superfícies em azul-escuro, textos claros e um único destaque azul.
- **Animações de entrada:** elementos com efeito de revelação durante a rolagem; a preferência por movimento reduzido do sistema é respeitada.
- **Tela de carregamento:** transição visual inicial.
- **Terminal interativo:** disponível na página inicial para consultar informações, listar páginas e navegar pelo site.
- **Player de música:** controle para tocar ou pausar `src/audio/VIEWS.mp3`. O estado de reprodução e a posição são guardados no `localStorage`; o navegador pode limitar a reprodução automática.
- **Currículo em PDF:** disponível em `src/docs/(CV) - Bruno Dev Novo.pdf`.
- **Galeria de projetos:** cartões com imagem, descrição, tecnologias e links de demonstração ou repositório quando disponíveis.
- **Certificados:** filtros por emissor, modal para ampliar a imagem e botão para baixar o PDF.
- **Links externos:** acesso aos perfis e repositórios relacionados.

| `certificados` ou `certificado` | Abre a página Certificados. |
| `contato` | Abre a página Contato. |

## Identidade visual

A interface usa uma paleta escura e minimalista com **azul como cor de destaque**, para manter o visual profissional e consistente entre as páginas.

| Uso | Cor |
|---|---|
| Destaque principal | `#60A5FA` |
| Destaque claro / hover | `#93C5FD` |
| Fundo principal | `#0B1120` |
| Superfícies | `#111827` e `#0F172A` |
| Texto principal | `#F1F5F9` |
| Texto secundário | `#94A3B8` |

As variáveis globais estão em `src/css/root.css`. Para ajustar a cor principal, atualize `--color-primary`, `--color-primary-hover`, `--color-primary-light` e `--color-primary-rgb`. Os estilos das páginas utilizam esses tokens para manter o destaque alinhado.

## Como executar localmente

O projeto é estático e não precisa instalar dependências para a visualização básica.

1. Clone o repositório:

   ```bash
   git clone https://github.com/IBrunooDev/Projeto-Portfolio.git
   ```

2. Abra a pasta no Visual Studio Code.
3. Inicie `index.html` com a extensão **Live Server** ou abra o arquivo diretamente no navegador.
4. Navegue pelas páginas e teste o terminal, o menu mobile, o player, os links, o currículo e a área de certificados.

Não há etapa de build ou comando `npm run` configurado no projeto atual.

## Manutenção

- `src/css/root.css`: variáveis de cores, tipografia, espaçamento e componentes base.
- `src/css/global.css`: reset, layout base, botões, rodapé e utilitários.
- `src/css/navbar.css`: cabeçalho e navegação desktop/mobile.
- `src/css/redesign.css`: camada de ajustes visuais compartilhados do redesign.
- Demais arquivos em `src/css/`: estilos específicos das páginas e componentes.
- `src/js/navbar.js`: página ativa, menu mobile e fechamento da navegação.
- `src/js/main.js`: tela de carregamento, animações de entrada e player de música.
- `src/js/terminal.js`: comandos do terminal da página inicial.
- `src/js/certificates.js`: dados, filtros, modal e downloads dos certificados.

### Adicionar um certificado

1. Adicione a imagem de pré-visualização em `src/img/certificates/`.
2. Adicione o PDF correspondente em `src/docs/certificates/`.
3. Inclua os dados no array `CERTIFICATES` em `src/js/certificates.js`, conferindo os caminhos, o nome, o emissor e o ano.

## Responsividade e acessibilidade

O projeto inclui menu mobile, textos alternativos nas imagens principais, foco visível para navegação por teclado e respeito à preferência do sistema por movimento reduzido nas animações. Ainda é recomendável testar manualmente os modais, controles e links em navegadores e tamanhos de tela diferentes.
