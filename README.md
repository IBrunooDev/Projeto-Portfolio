## Sobre o projeto

O site foi criado para apresentar o perfil profissional de Bruno Henrique e centralizar informações relevantes para recrutadores, clientes e colaboradores. A interface combina um visual moderno e futurista com tipografia técnica, fundo em grid, detalhes em verde e uma experiência de navegação inspirada em terminal.

O conteúdo destaca conhecimentos em desenvolvimento front-end, projetos práticos, formação, certificados e disponibilidade para oportunidades profissionais, trabalhos freelance e colaborações.

## Principais recursos

- Site multipágina com navegação entre sete áreas.
- Layout responsivo para computadores, tablets e celulares.
- Menu mobile com controle de abertura e indicação da página ativa.
- Tela de carregamento exibida durante a entrada nas páginas.
- Animações de revelação conforme o conteúdo aparece na tela.
- Terminal interativo com comandos informativos e atalhos de navegação.
- Player de música fixo com reprodução em loop.
- Persistência do estado e do tempo do áudio usando `localStorage`.
- Download do currículo em PDF diretamente pela página inicial.
- Seção com seis projetos, links de demonstração e repositórios.
- Grade de habilidades com ícones do Devicon.
- Linha do tempo da trajetória profissional e acadêmica.
- Galeria de certificados com filtros por instituição.
- Visualização ampliada dos certificados em modal.
- Download dos certificados em PDF.
- Fechamento do modal por botão, clique externo ou tecla `Escape`.
- Sistema de design centralizado com variáveis CSS.
- Estados de foco visíveis, textos alternativos e atributos ARIA em elementos interativos.

## Como executar localmente

Este é um projeto estático e não exige instalação de dependências.

### Opção 1 — Live Server

1. Baixe ou clone o repositório.
2. Abra a pasta no Visual Studio Code.
3. Instale a extensão **Live Server**, se necessário.
4. Clique com o botão direito em `index.html`.
5. Selecione **Open with Live Server**.

### Opção 2 — Servidor local pelo terminal

```bash
git clone https://github.com/IBrunooDev/Projeto-Portfolio.git
cd Projeto-Portfolio
python -m http.server 5500
```

Depois, acesse `http://localhost:5500` no navegador.

No Windows, caso o comando `python` não funcione, utilize:

```bash
py -m http.server 5500
```

## Personalização

### Alterar cores, fontes e espaçamentos

Edite as variáveis de `src/css/root.css`. Esse arquivo concentra cores, tipografia, espaçamentos, bordas, sombras, transições, tamanhos de container e camadas de `z-index`.

```css
:root {
  --color-primary: #3f8f7f;
  --color-bg: #0c0e11;
  --color-text: #e8eaee;
  --font-sans: "IBM Plex Sans", "Segoe UI", sans-serif;
  --font-mono: "IBM Plex Mono", "Consolas", monospace;
}
```

### Adicionar um projeto

1. Coloque a imagem em `src/img/`.
2. Abra `projetos.html`.
3. Duplique um elemento `<article class="project-card">`.
4. Atualize imagem, título, descrição, tecnologias, demonstração e repositório.
5. Ajuste a numeração e a quantidade total mostrada no cabeçalho da seção.

### Adicionar um certificado

1. Coloque a imagem JPG ou PNG em `src/img/certificates/`.
2. Coloque o PDF em `src/docs/certificates/`.
3. Abra `src/js/certificates.js`.
4. Adicione um objeto ao array `CERTIFICATES`:

```js
{
  id: "instituicao-curso",
  name: "Nome do curso",
  issuer: "Instituição",
  date: "2026",
  image: "src/img/certificates/certificado.jpg",
  pdf: "src/docs/certificates/certificado.pdf",
}
```

Os botões de filtro são criados automaticamente a partir do campo `issuer`.

### Alterar currículo, perfil ou música

- Substitua o currículo em `src/docs/` e atualize o link em `index.html` caso o nome do arquivo mude.
- Atualize as imagens de perfil e dos projetos dentro de `src/img/`.
- Substitua o arquivo em `src/audio/` e altere o nome e o caminho em `src/js/main.js`.
