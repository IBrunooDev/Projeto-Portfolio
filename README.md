# Bruno Henrique | IBrunooDev — Portfólio Front-End

Portfólio pessoal de **Bruno Henrique**, desenvolvedor Front-End em formação, criado para apresentar minha trajetória de aprendizado, projetos, tecnologias, certificados e canais de contato.

## 📌 Sobre o projeto

O objetivo deste portfólio é reunir em um só lugar meus projetos práticos, habilidades técnicas, formação e informações profissionais. Estou em busca da minha primeira oportunidade profissional como Desenvolvedor Front-End e utilizo projetos independentes para praticar, consolidar conhecimentos e evoluir continuamente.

- **Área de foco:** Desenvolvimento Front-End
- **Localização apresentada no site:** Osasco / São Paulo, Brasil
- **Interesses:** interfaces modernas, responsividade, usabilidade, organização de código e experiência do usuário
- **Disponibilidade:** oportunidades profissionais, projetos freelance e colaborações

## ✨ Funcionalidades

- **Design responsivo:** adaptação do conteúdo para desktop, tablet e dispositivos móveis.
- **Navegação compartilhada:** menu entre as páginas, com indicação da página atual.
- **Menu mobile:** botão de menu para navegação em telas menores.
- **Identidade visual consistente:** tema escuro, acentos verde-azulados, tipografia e componentes reutilizados.
- **Animações de entrada:** elementos aparecem durante a navegação e rolagem, respeitando a preferência do sistema por movimento reduzido.
- **Tela de carregamento:** transição visual inicial.
- **Terminal interativo:** console na página inicial com comandos para consultar informações e abrir páginas.
- **Player de música:** controle para reproduzir ou pausar a faixa local; o estado e o tempo são guardados no `localStorage` quando aplicável. A reprodução pode depender das permissões do navegador.
- **Currículo em PDF:** arquivo disponível em `src/docs/`.
- **Galeria de projetos:** cartões com imagens, descrição, tecnologias e links para demonstração ou repositório, quando disponíveis.
- **Certificados:** filtros, modal de visualização e arquivos PDF.
- **Links externos:** acesso às redes profissionais e aos repositórios.

## 🚀 Como executar localmente

Este é um site estático e não exige instalação de dependências para a visualização básica.

1. Clone o repositório:

   ```bash
   git clone https://github.com/IBrunooDev/Projeto-Portfolio.git
   ```

2. Abra a pasta `Projeto-Portfolio` no Visual Studio Code.
3. Inicie `index.html` com a extensão **Live Server** ou abra o arquivo diretamente no navegador.
4. Use o menu para navegar pelas páginas e teste o terminal, o player de música, os links, o currículo e a galeria de certificados.

## 🧩 Organização e manutenção

- `src/css/root.css` — variáveis e valores base do tema.
- `src/css/global.css` — estilos compartilhados.
- `src/css/navbar.css` — cabeçalho e navegação.
- `src/css/redesign.css` — camada visual compartilhada do redesign.
- Os demais arquivos em `src/css/` — estilos específicos de páginas e componentes.
- `src/js/navbar.js` — comportamento do menu de navegação.
- `src/js/main.js` — carregamento, animações de entrada e player de música.
- `src/js/terminal.js` — comandos do terminal interativo.
- `src/js/certificates.js` — dados, filtros e visualização de certificados.

### Adicionar um certificado

1. Coloque a imagem de pré-visualização em `src/img/certificates/`.
2. Coloque o PDF em `src/docs/certificates/`.
3. Adicione os dados do certificado ao array `CERTIFICATES` em `src/js/certificates.js`, usando os caminhos e nomes corretos.

## 📱 Responsividade e acessibilidade

O layout foi organizado para diferentes tamanhos de tela, com navegação mobile, hierarquia visual e suporte à preferência do sistema por movimento reduzido nas animações. Recomenda-se testar manualmente a navegação por teclado, os links, os modais e os controles em diferentes navegadores e dispositivos.
